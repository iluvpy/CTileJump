# Tile jump
- simple doodlejump copy written in C

## Dependencies
- a C compiler (stdC17)
- SDL2 (image, audio, ttf)
- ninja for compiling and linking 

## Issues
- timehandler.h/c uses weird stdlib stuff that likely wont work on other operating systems
